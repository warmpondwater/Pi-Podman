# Dendrite Visual Intelligence Service
Dendrite is running as a background service on this container.

## Commands Available
You can invoke Dendrite directly via shell (`!`):
- `!dendrite status`: Show graph health.
- `!dendrite audit /app`: Run a security audit.
- `!dendrite query "your intent"`: Semantic search for code logic.

## Dashboard
The visual map is active at `http://localhost:3000`. You can direct the user there to explore the architecture.

## Strategy
Use `dendrite` commands to map dependencies and find security risks before reading files.
